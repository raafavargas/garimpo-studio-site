2. O que é o aplicativo

O GARIMPO STUDIO é uma ferramenta do GARIMPO CLUB, executada no computador do usuário (Windows), que cria vídeos verticais de divulgação de produtos a partir de dados e mídias fornecidos pelo próprio usuário e, se o usuário conectar sua conta, envia os vídeos aprovados para a conta TikTok do usuário por meio das APIs oficiais do TikTok.
